# IPv6 任意有効化の実装計画

> 実行担当: `superpowers:executing-plans` を使い、このセッションで順に実施する。ユーザー承認済みの方針と実装判断の委任に従い、重複した承認は求めない。

**目的:** 既存 IPv4 動作を維持したまま、IPv6 の通信にも許可リストを適用する。

**構成:** launcher が固定 Compose override を選び、entrypoint が同じモードを初期化と更新へ渡す。IPv6 固有の処理は Python 標準ライブラリと ip6tables を使う専用アセットにまとめる。

**技術:** Bash、Python3標準ライブラリ、Podman/pasta、Compose、iptables/ip6tables、dig。

**設計:** `docs/superpowers/specs/2026-09-13-ipv6-design.md`

## 共通条件

- 設定は `CLAUDE_CONTAINER_IPV6=1`。未指定・空・0は既定、その他拒否。
- ホスト/WARP の自動変更なし。IPv4-only が既定。IPv6-only は対象外。
- データをシェルコードとして解釈しない。ルール追加前に入力を検証する。
- 新規依存は固定の `python3` のみ。Python外部パッケージなし。
- 文書・メッセージは日本語。変更を実際に検出するテストから書く。
