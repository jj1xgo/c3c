# ホスト `~/.claude/.git` をコンテナから読み取り専用にする計画（#129）

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task.

> 実行担当: Claude（Opus 5、本セッション内で `/model` 切替後。末尾「実装者」参照）。編集対象は `claude-container`・`compose.yml`・`test-build.sh`・`README.md`・`docs/runtime-ci.md`・`docs/development-invariants.md` の 6 ファイルで、置換文と Expected は逐語で確定している（計画時にコンテナ内の使い捨て worktree で赤→緑を実測済み）。

**目的:** ホストの `~/.claude` が git リポジトリのとき、コンテナ内から `~/.claude/.git`（`.git/hooks/*`・`.git/config` の `core.hooksPath`・`core.fsmonitor`・`core.pager`・`filter.*` 等）を書き換えられ、ホストで `git -C ~/.claude commit` 等を打った時点でホスト権限の任意コマンド実行につながる経路を閉じる。`~/.claude` がリポジトリでないホストでも、コンテナが `.git` を植え付けて後日の `git init`（既存 `.git` を再利用する）で有効化される経路を同時に閉じる。

**構成:** v8.2.0（`0a064c9`）の user scope 設定 11 項目の `:ro` 重ねマウントに `.git` を 12 項目目として加える。`claude-container` の `CLAUDE_CONFIG_RO_DIRS`、`compose.yml` の volumes、`test-build.sh` の `CONFIG_RO_DIRS` を同期し（既存コメントが要求する 3 箇所同期）、無いホストでは `prepare_claude_config_ro()` が既存の流儀で空ディレクトリを作る。新しいガードや override は作らない。

**根拠（1 次情報、2026-09-19 にコンテナ内で実測。main `ab53039`）:**

- コンテナ内で `test -w ~/.claude/.git` が真、`touch ~/.claude/.git/config` が成功。`compose.yml` 48 行目の親マウント（rw）の内側で `.git` に `:ro` が無い。`git -C ~/.claude config --get core.hooksPath` は未設定、`.git/hooks` は sample のみ（現時点で改変なし）。
- 空の `.git` ディレクトリは git に無視される: 親ディレクトリを repo にした状態で `.claude/a` を置くと `git status` は `?? .claude/a`（入れ子 repo 扱いでない）、`.claude` 内からの `git rev-parse --show-toplevel` は親を返す。空の `.git` に対する `git init` は通常どおり `HEAD`・`config` 等を作る。よって「無ければ空で作る」既存の流儀を `.git` に適用してもホストの git 操作を壊さない。
- 使い捨て worktree で Task 1〜2 を逐語適用した dry run: Task 1 後の `TMPDIR=/tmp ./test-build.sh --launcher-only` は「A: 作成を 12 行ログする」だけ `[FAIL]`（`PASS=245 FAIL=1`）。Task 2 後は `PASS=246 FAIL=0`、`./lint.sh` rc=0（コンテナ内のため compose 検証は WARNING でスキップ）。
- Issue: [jj1xgo/claude-container#129](https://github.com/jj1xgo/claude-container/issues/129)。発見の経緯: 2026-09-19 にホストの `~/.claude` を allowlist 方式の git リポジトリ（`jj1xgo/dotclaude`）にした際の handover の未解決事項。
